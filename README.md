# رابط للحجوزات – Rabit Bookings

منصة حجوزات ليبية: سوق (Marketplace) + نظام SaaS + محفظة إلكترونية + كروت شحن + نظام أدوار وصلاحيات.

- **الواجهة العامة:** فنادق، منتجعات، رياضة، أفراح، صحة، جمال، مطاعم، سيارات، سفر، ترفيه، أعمال، تصوير، أطفال، تعليم، تذاكر فعاليات.
- **الحافلات بين المدن:** بحث، خريطة مقاعد، ودفع من المحفظة.
- **تذاكر المباريات والفعاليات:** فئات تذاكر، حماية من البيع المزدوج، تذكرة إلكترونية.
- **رابط الصحي:** مقارنة المصحات + طلب مكالمة من مستشار صحي.
- **الأدوار:** عميل / مزود خدمة / موظف (صلاحيات مخصصة) / إدارة / إدارة عليا — وكل دور له واجهته.
- **المحفظة:** دفتر حركات مالي كامل، شحن بكروت مسبقة الدفع (مخزّنة كمُلخّص تشفيري لا كنص مكشوف)، مزايا VIP.

## البدء السريع
```bash
npm install
cp .env.example .env         # ثم عدّل DATABASE_URL
node scripts/create-tables.js "$DATABASE_URL"   # ينشئ 35 جدولاً (آمن للتكرار)
npm run dev
```

## النشر
- **Render.com:** اقرأ `RENDER.md` (يوجد ملف `render.yaml` للنشر التلقائي).
- **Vercel + Neon:** اقرأ `DEPLOY.md`.
